ПЛАТНЫЙ ДОМ — единый сайт и игровой сервер (Railway)
====================================================

ЧТО МЕНЯЕТСЯ
------------
- Render больше не используется.
- GitHub Pages больше не используется для открытия игры.
- Один Node.js-сервис раздаёт index.html, /health, /test и Socket.IO.
- Игра подключается к Socket.IO через window.location.origin.
- Скрипт Socket.IO загружается с этого же адреса: /socket.io/socket.io.js.
- Поэтому браузеру не нужно обращаться с мобильного телефона к отдельному домену игрового API и выполнять cross-origin запросы.

СТРУКТУРА КОРНЯ РЕПОЗИТОРИЯ
---------------------------
Game-server/
  index.html
  server.js
  package.json
  test.html
  README_RAILWAY_RU.txt

ВАЖНО: все четыре рабочих файла должны лежать прямо в корне репозитория.
Не задавайте Root Directory = server. На Railway оставьте Root Directory пустым.

ШАГ 1. ОБНОВИТЬ GITHUB
----------------------
1. Откройте репозиторий Game-server.
2. Загрузите файлы из этого архива в КОРЕНЬ репозитория.
3. Замените старые server.js и package.json.
4. Добавьте index.html и test.html.
5. Сделайте Commit changes.

ШАГ 2. СОЗДАТЬ RAILWAY-СЕРВИС
-----------------------------
1. Откройте https://railway.com/ и войдите через GitHub.
2. Нажмите New Project.
3. Выберите Deploy from GitHub Repo.
4. Выберите репозиторий Game-server и разрешите Railway доступ к нему.
5. У сервиса откройте Settings.
6. Root Directory оставьте пустым.
7. Убедитесь, что Start Command = npm start. Если поле пустое и Railway определил Node.js автоматически, можно оставить автоматическое определение.
8. В Networking выберите Generate Domain.
9. Оставьте одну реплику (один запущенный экземпляр), поскольку список комнат хранится в памяти процесса.

Build Command: npm install
Start Command: npm start

Приложение читает PORT из process.env.PORT и слушает 0.0.0.0.
Healthcheck path для Railway, если он предлагается: /health.

ШАГ 3. ПРОВЕРИТЬ С ТЕЛЕФОНА ДО ЗАМЕНЫ ССЫЛОК
-------------------------------------------
После статуса Deploy successful скопируйте созданный Railway-домен, например:
https://ИМЯ-ПРОЕКТА.up.railway.app

На телефоне выключите Wi-Fi и откройте по мобильному интернету:
  https://ИМЯ-ПРОЕКТА.up.railway.app/health
  https://ИМЯ-ПРОЕКТА.up.railway.app/test

На /health должен вернуться JSON с ok:true и transport:"socket.io".
На /test дождитесь «Соединение установлено», затем нажмите «Отправить тестовое сообщение».
В результате ожидается «УСПЕШНО» с socketId и transport.

Если /health работает, а /test не соединяется, пришлите скриншот /test и Railway Deploy Logs.
Если даже /health не открывается через мобильный интернет, не переходите к тестированию игры: сначала нужно разобраться с доступностью нового домена из мобильной сети.

ШАГ 4. ЗАПУСТИТЬ ИГРУ
---------------------
Откройте корень того же Railway-домена:
  https://ИМЯ-ПРОЕКТА.up.railway.app/

Игра и Socket.IO уже используют один origin. Никакой отдельный GAME_SERVER_URL редактировать не надо.
Не открывайте старую GitHub Pages-ссылку — она больше не является рабочей точкой входа для этой сборки.
Сохраните Railway URL и используйте его на компьютере и телефоне.

ЧТО СОХРАНЕНО
--------------
- Игровая карта, экономика, комнаты персонажей, суд, казино и остальные игровые механики.
- Мобильное управление.
- Открытые и закрытые лобби; пароль проверяется на сервере и не показывается в каталоге.
- Список комнат, вход по коду, чат и игровые обновления через Socket.IO.
- Голосовой чат и WebRTC-сигналинг.

ОГРАНИЧЕНИЯ
-----------
- Список лобби хранится в памяти одного процесса. При перезапуске приложения комнаты закрываются.
- Не включайте несколько реплик без переноса состояния комнат в общую БД/Redis.
- Хост должен оставаться в игре во время матча: он по-прежнему рассчитывает игровое состояние. Если браузер хоста закрыт или выгружен телефоном, комната завершится.
- Для голосовой связи в некоторых сетях может понадобиться TURN-сервер; текстовый/игровой обмен Socket.IO от этого не зависит.
- Railway — не прежний бесплатный Render: перед продолжительным использованием проверьте текущие лимиты и стоимость выбранного плана в аккаунте Railway.

ПЕРЕД ПУБЛИКАЦИЕЙ
-----------------
Сборка подготовлена для Node.js 18+ и существующего протокола Socket.IO. Синтаксис server.js и игрового JavaScript следует проверить после распаковки; реальное соединение можно считать подтверждённым только после теста /test с телефона через мобильный интернет.
